# Output Schema — Flutter Expert

## Files Produced

Output depends on the `LAYER` requested.

### Presentation Layer

| File | Template Used |
|---|---|
| `lib/features/<feature>/presentation/screens/<name>_screen.dart` | ConsumerWidget or ConsumerStatefulWidget |
| `lib/features/<feature>/presentation/widgets/<name>_widget.dart` | ConsumerWidget |
| `lib/features/<feature>/presentation/notifiers/<name>_notifier.dart` | AsyncNotifier or Notifier |
| `lib/features/<feature>/presentation/notifiers/<name>_notifier.g.dart` | Generated by build_runner |

### Domain Layer

| File | Template Used |
|---|---|
| `lib/features/<feature>/domain/entities/<name>.dart` | Freezed entity |
| `lib/features/<feature>/domain/usecases/<name>_use_case.dart` | UseCase class |
| `lib/features/<feature>/domain/repositories/<name>_repository.dart` | Abstract interface |

### Data Layer

| File | Template Used |
|---|---|
| `lib/features/<feature>/data/repositories/<name>_repository_impl.dart` | Repository implementation |
| `lib/features/<feature>/data/datasources/<name>_local_data_source.dart` | Hive data source |

### DI Registration

| File | Change |
|---|---|
| `lib/core/di/providers.dart` | New `@riverpod` provider functions added |

### Router Registration (if new screen)

| File | Change |
|---|---|
| `lib/core/router/app_router.dart` | New `GoRoute` entry added |

## Code Quality Standards

All generated files must:
- Have zero `flutter analyze` warnings
- Pass `dart format` without changes
- Use `const` constructors wherever possible
- Keep `build()` under 50 lines — extract named private widgets
- Have no `print()` calls — use `debugPrint()` or a logger
