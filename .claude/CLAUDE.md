# Prompt App — Claude Context

Prompt App is a Flutter application that transforms simple user prompts into powerful, well-structured AI prompts using a curated library of prompt patterns.

## Core Concept

```
User input (simple) → Pattern Engine → Enhanced prompt (powerful)
```

The app does NOT teach users how to prompt. It does the work for them by applying proven prompt patterns automatically.
